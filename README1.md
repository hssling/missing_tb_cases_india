# State-wise Missed Tuberculosis Cases in India

This repository automates the estimation of “missed” TB cases (incident cases that are not notified) for India overall and for each state/UT. The pipeline ingests official WHO CSV exports, Ni-kshay/India TB Report notification tables, the National TB Prevalence Survey, and NFHS-5 socio-demographic indicators, then harmonises them into analysis-ready panels, figures, and manuscripts.

**Missed cases(s,t) = Incidence_est(s,t) – Notifications(s,t)**  
where *s* is the state and *t* is the year.

```
├── output/
│   ├── figures/     # Plots generated by scripts/05 and 06

│   └── dashboards/  # Files ready for BI tooling
├── reports/
│   ├── protocol_draft.md

│   └── state_profiles/ (optional)

```

All scripts rely on relative paths from the repository root, so the workflow runs identically across Windows, macOS, and CI runners.

## Required inputs (`data/raw/`)

| File | Description |
| --- | --- |
| `TB_burden_countries_2025-11-23.csv` | WHO TB burden extract (country × year) with incidence/mortality. |
| `TB_notifications_2025-11-23.csv` | WHO notification extract with `c_newinc` totals. |
| `RS_Session_260_AU_618_A_to_B_i.csv` | Ni-kshay/Rajya Sabha state notifications (2020–2023). |
| `RS_Session_266_AU_1736_A_to_C_3 (1).csv` and `_C_4.csv` | Age/death distributions (2023/2024). |
| `RS_Session_266_AU_2511_1.csv` and `RS_Session_267_AU_3467_1.csv` | 2024 year-to-date notifications/deaths and treatment outcomes. |
| `2.10_TB_Diabetes.csv`, `2.11_TB_Tobacco.csv`, `2.12_TB_Alcohol.csv` | Cascade indicators from India TB Report 2024. |
| `nfhs5_state_agg.csv` | NFHS-5 state-level risk indicators. |

Optional inputs (prevalence survey, census covariates, priors) can be added later; scripts log informative warnings when optional files are missing.

## Automated pipeline

1. **Literature search** – `python scripts/00_lit_search.py`  
   Pulls PubMed metadata for TB under-reporting/cascade studies (`lit/lit_db.csv`).

2. **(Optional) Legacy WHO downloader** – `python scripts/01_download_who_data.py`  
   Retained for backwards compatibility; modern runs should prefer the offline WHO exports plus script 07 (below).

3. **Ni-kshay ingestion** – `python scripts/02_ingest_india_tb_reports.py`  
   Cleans the state notification Excel/CSV export into `data/processed/india_tb_state_notif.csv`.

4. **State covariate merge** – `python scripts/03_build_state_panel.py`  
   Merges NFHS, Census, prevalence survey (if provided), and cascade priors to form `data/processed/state_year_panel.csv`.

5. **(Optional) Bayesian model** – `python scripts/04_fit_bayesian_model.py`  
   Placeholder PyMC workflow; run only if you have priors and a compatible environment.

6. **Posterior summariser & reporting** – `python scripts/05_scenarios_and_outputs.py`  
   Consumes Bayesian draws (if present) to produce tables/plots; can be skipped when using the deterministic calibration (script 06).

7. **WHO resource processing** – `python scripts/07_process_who_resource_files.py`  
   Converts the WHO burden and notification CSVs into `data/processed/who_india_ts.csv`.

8. **Deterministic gap analysis** – `python scripts/06_state_gap_analysis.py`  
   - Builds system-strength and risk indices from cascade + NFHS data.  
   - Scales state notifications so each year matches WHO’s national `c_newinc`.  
   - Calibrates detection probabilities so summed incidence equals WHO incidence.  
   - Outputs detection panels (`output/tables/state_detection_panel.csv`), scenario tables, figures, and updates `reports/analysis_summary.md` plus `reports/tb_manuscript.md`.

Re-run scripts 6–7 whenever new WHO/Ni-kshay data drop. If you add new raw files, simply place them in `data/raw/` and rerun the relevant scripts; no path tweaks are necessary.
